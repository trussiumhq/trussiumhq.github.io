# Documentation governance

Technical documentation is maintained with the component it describes:

- [Runtime documentation](https://github.com/trussiumhq/trussium) is maintained
  with the runtime source and releases.
- [Operator documentation](https://github.com/trussiumhq/trussium-operator) is
  maintained with the Kubernetes API and controller implementation.
- [Helm documentation](https://github.com/trussiumhq/trussium-helm) is
  maintained with the chart and its release process.

This repository governs the shared documentation portal, including navigation,
presentation, build, and publication. Contributions should preserve clear
ownership and ensure operational guidance remains aligned with the relevant
release.
