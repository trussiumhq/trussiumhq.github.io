# Trussium Governance

## Scope

Trussium is an open-source, provider-neutral, cloud-native runtime project.
The project includes the Runtime, Kubernetes Operator, Helm chart, and shared
documentation portal.

## Maintainers

Maintainers are listed in [MAINTAINERS.md](MAINTAINERS.md). They are responsible
for reviewing contributions, maintaining project quality, responding to
security reports, and stewarding a healthy contributor community.

New maintainers are proposed by an existing maintainer based on sustained,
high-quality contributions and demonstrated alignment with the project’s Code
of Conduct. The existing maintainers decide by consensus and record the outcome
in a public project issue or pull request.

## Decision-making

Technical decisions are made openly in issues and pull requests in the
repository that owns the affected component. Maintainers seek consensus among
active contributors. When consensus is not reached in a reasonable period, the
maintainers responsible for that component make the decision and document the
rationale.

Material, cross-component decisions should be recorded as an Architecture
Decision Record or comparable public design document.

## Changes to governance

Changes to this document, the Code of Conduct, or the maintainer roster require
a public pull request and approval from at least two maintainers, once the
project has two or more active maintainers. Until then, the sole listed
maintainer records the rationale in the pull request.
