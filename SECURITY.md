# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through GitHub’s **Report a
vulnerability** facility in the affected Trussium repository. Do not report
security issues in public GitHub issues, discussions, or pull requests.

This policy applies to:

- [Trussium Runtime](https://github.com/trussiumhq/trussium)
- [Trussium Operator](https://github.com/trussiumhq/trussium-operator)
- [Trussium Helm chart](https://github.com/trussiumhq/trussium-helm)
- [Trussium project website](https://github.com/trussiumhq/trussiumhq.github.io)

Include the affected component and version, a description of the impact, clear
reproduction steps or a proof of concept where safe to provide, and any known
mitigations.

## Response process

Maintainers will acknowledge valid reports, assess impact and affected versions,
coordinate a fix, and publish appropriate release and disclosure information.
Please allow maintainers reasonable time to investigate and remediate an issue
before public disclosure.
